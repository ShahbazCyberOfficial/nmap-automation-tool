# Nmap Automation Tool

## Description

A simple Python automation tool that performs an Nmap scan using subprocess.

The tool performs:

- SYN Scan
- Service Version Detection
- OS Detection
- Aggressive Scan
- Automatically saves the scan report

---

## Requirements

- Python 3.x
- Nmap installed
- Linux or Windows (with Nmap in PATH)

---

## Usage

Run:

```bash
chmod +x nmap_automation.py
python3 nmap_automation.py
```

Enter:

- Target IP Address
- Report File Name

The report will be saved automatically.

# Go to the project directory
cd nmap-automation-tool
