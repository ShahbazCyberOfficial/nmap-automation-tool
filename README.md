# 🚀 NMAP Automation Tool

A lightweight and beginner-friendly Python automation tool that simplifies Nmap scanning using a clean command-line interface. This tool automates common reconnaissance tasks and automatically saves scan results into a report file.

# ⭐ Overview

This automation tool is designed for students, cybersecurity learners, and penetration testers who want to perform Nmap scans quickly without remembering long command-line arguments.

Simply provide:

- Target IP Address
- Report File Name

The tool automatically performs the scan and saves the results.

---

# 🔥 Key Features

- ✔ TCP SYN Scan (-sS)
- ✔ Service Version Detection (-sV)
- ✔ Operating System Detection (-O)
- ✔ Aggressive Scan (-A)
- ✔ Full Port Scan (-p-)
- ✔ Automatic Report Saving
- ✔ Beginner-Friendly Interface
- ✔ Fast & Lightweight
- ✔ Easy to Use

# 🚀 Quick Start

Run:

```bash
python3 nmap_automation.py
```

Example Target:

```
192.168.1.10
```

or

```
scanme.nmap.org
```

Example Report Name:

```
report.txt
```
